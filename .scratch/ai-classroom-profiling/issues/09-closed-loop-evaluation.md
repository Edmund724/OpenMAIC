# T6：闭环评估机制

Type: grilling
Status: resolved
Blocked by: 08

## Question

定"闭环如何闭合"：用什么指标判断自适应有效（掌握度提升、达标耗时、投入度变化、补习后回归主线的成功率），评估的频率与方式（课内即时/阶段性/课程结束），评估结果如何反过来调整采集、画像与策略参数（第二阶闭环），以及 MVP 做到多严谨（对照实验 vs 观察性指标）。

会话开场调 Skill: grilling + domain-modeling。

## Answer

2026-09-20 经一轮 grilling 拍板（Q5 用户改为 A+B 全要，其余按推荐）：

1. **三层指标体系**：学习成效层（BKT 掌握度曲线、达标耗时、阶段测验成绩）；机制健康层（补习触发率、补习后回归成功率、加速确认测通过率=BKT 高估检测器、深化模块完成率）；体验层（投入度趋势、概念性提问占比变化）。
2. **评估节奏**：机制健康层持续可查；三层指标每模块结束例行回顾；整体评估课程结束。与学生侧"每阶段末画像重提炼"同节奏，共用派生计算。
3. **MVP 严谨度**：观察性指标 + 前后趋势起步，不设对照组（样本量与伦理双重原因，简单指标 + 透明口径优先）；事件与画像存储预留按学生分桶开关策略的能力，A/B 作为远期选项。
4. **第二阶闭环（三条回调通道）**：阈值校准（0.6/0.85 初始为待校准值，用触发率与确认测通过率回调）；LLM 打标小比例人工抽检（教师/运营）；回归成功率低的补习模块进教师队列重写或固化。责任人 = 教师（每模块末 + 学期末例行回顾，系统出报告），MVP 不做自动调参。
5. **教师端学情视图（按用户决定，A+B 均进 MVP）**：班级聚合三件套（卡点概念排行、三态触发统计、全班掌握热力分布）**加**个体级视图（教师可看单个学生的掌握地图；仍不见对话原文与行为标签，T1 边界不变）。
