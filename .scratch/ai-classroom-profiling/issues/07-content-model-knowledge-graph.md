# T4：课程内容模型与知识图谱

Type: grilling
Status: resolved
Blocked by: 01

## Question

定 L2 自适应的内容地基：课程如何被结构化为"概念级知识图谱 + 先修链"（用户已确认概念级粒度）——AI 从教师上传材料自动抽取还是教师标注、抽取错误谁兜底、教师在建谱中的角色（产品是教师上传制，不是完全 AI 课堂）；补习模块与深化模块从哪来（AI 基于材料生成/教师预编/混合）、模块的粒度与挂接方式。

参照：OpenMAIC 知识库构建在开源版缺失、论文主张 taxonomic 知识库（调研报告 2.1 节）；R1 结论（`.scratch/ai-classroom-profiling/research/01-maic-paper-profiling.md`）。会话开场调 Skill: grilling + domain-modeling。

## Answer

2026-09-20 经一轮 grilling 全部按推荐拍板：

1. **建谱方式：AI 抽取 + 教师审校**。AI 从教师上传材料抽出概念清单与先修链，教师发布前审校修正；教师角色是"审校者"而非"录入员"。拒绝免审（图谱错 → BKT 归因错 → 补习补错）。
2. **图谱结构**：概念节点（一门课 100–300 个）+ 先修有向边 + 两张映射表——概念 → 材料片段（视频时间区间/PPT 页/PDF 段落）、概念 → 测验题。课程章节树保留为组织外壳，图谱专管跨章节先修关系。
3. **错误兜底与版本化**：发布前教师必审（AI 全量抽、教师只看低置信边与主干先修链）；运行时学生/助教可标记概念问题进教师队列；**图谱版本化——概念 ID 稳定，修改 = 新增/废弃而非改写**（画像挂在概念 ID 上，图谱迭代不得毁掉既有画像证据）。
4. **补习模块：AI 生成为主，教师对高频触发模块审校固化**。AI 沿"概念 → 材料片段"映射找原文，重组讲解 + 出题；模块形态 = 概念讲解（文字讲稿）+ 材料片段重看指引 + 2–3 题巩固练习。教师零额外负担起步。
5. **深化模块：MVP 只做课内加深**（课程内高阶概念前置 + AI 生成进阶练习/开放讨论题，事实性有课程材料兜底）；开放外拓（前沿论文、工程实践）放远期；教师可选提供"拓展方向白名单"约束生成边界。
6. **模块粒度与挂接**：模块 = 单概念或 ≤3 概念小簇；类型三选（讲解/练习/讨论）；标注目标层级（补基础/标准/深化）；统一挂概念 ID，由 T5 策略引擎按画像调用。
