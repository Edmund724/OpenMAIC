# T1：交互采集清单与事件模型

Type: grilling
Status: resolved
Blocked by: 01, 03

## Question

定产品"采集什么"：交互事件的完整清单、分类法与粒度。候选面：助教问答（消息本体、对话行为类型）、测验作答（对错、逐题用时、修改痕迹）、视频行为（暂停/回看/倍速/弃看）、课件停留与翻页、课程总时长与学习节奏。对每类定：采不采、采到什么粒度、事件携带什么字段。

附带定：学习者身份模型（账号 vs 匿名设备）与数据保留边界。

参照：OpenMAIC 采集清单见 `reports/maic-interaction-collection-and-profiling.md` 第 3 节（注意其未采翻页/停留/逐题用时）；R1、R3 调研结论（见 `.scratch/ai-classroom-profiling/research/`）。会话开场调 Skill: grilling + domain-modeling。

## Answer

2026-09-20 经一轮 grilling 全部按推荐拍板：

1. **问答对话（核心）**：全量原文 + 上下文。每条消息存全文、时间戳、当时课件位置（视频秒位/PPT 页码/知识点）、学生点选引用的课件元素。对话行为标签等一律作为事后可重算的派生层，不在采集时锁死。
2. **视频行为**：采用 xAPI Video Profile 子集——play / pause / seek（带 from-to）/ complete / 倍速变更；事件驱动记录 played-segments（可生成观看热区、算完成率、区分首看与重看）；每条事件带 session-id；不做心跳埋点，标签页切换/隐藏时记一次暂停。判读纪律：开头瞬时退出按噪声过滤；首看/重看在派生层分开统计。
3. **PPT/PDF 课件**：底线为页级翻页事件 + 页级可见停留（可见性过滤）；学生主动高亮/批注若播放器已支持则顺带采，不为此专门开发功能。
4. **测验过程**：逐题记录题目 ID、所选答案、对错、逐题用时、答案修改轨迹（修改前后选项 + 次序——首次修改方向是有效信号，二次以上为噪声，故次序必存）。
5. **事件模型骨架**：统一事件信封 `{事件ID, 学习者ID, 会话ID, 时间戳, 课程ID, 资源定位, 事件类型, 载荷}`。课程总时长、每周活跃天数、视频完成率、CFA 等指标一律从信封派生计算，不单独埋点；原始事件流保持可重放。
6. **明确不采**：光标轨迹、滚动深度、鼠标移动（噪声大、无文献价值共识、隐私敏感）。
7. **学习者身份与数据边界**：账号制（跨设备连续画像是闭环根基，弃 OpenMAIC 的匿名设备 key 模式）；问答原文默认保留供画像计算、学生可请求删除；教师只见聚合层、不见个人对话原文。
