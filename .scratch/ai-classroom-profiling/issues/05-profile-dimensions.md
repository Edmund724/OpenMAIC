# T2：画像维度与数据结构

Type: grilling
Status: resolved
Blocked by: 02, 04

## Question

定学生画像的维度体系与数据结构。候选维度族：知识状态（概念级掌握度，依托 T4 知识图谱）、认知特征（学习速度、提问深度/质量）、行为特征（投入度、学习节奏）、背景先验（学历层次、兴趣——用户认为 OpenMAIC 止步于此太浅，但不必丢弃）。对每维定：进 MVP 还是远期、字段形状、更新来源（哪类采集事件喂养它）。

附带定：哪些画像字段对学生可见（学情面板外露什么）。

核心立场（用户已定）：超越 OpenMAIC 的单轴难度 tier；问答对话必须成为画像输入（机制细化在 T3）。参照 R2 调研（`.scratch/ai-classroom-profiling/research/02-dialogue-student-modeling.md`）。会话开场调 Skill: grilling + domain-modeling。

## Answer

2026-09-20 经一轮 grilling 全部按推荐拍板：

1. **三层骨架**：身份层（静态：课程身份——年级/专业/先修背景自述，兴趣标签树）、行为层（构成向量：对话行为分布、投入度聚合、测验过程特征）、状态层（动态估计：逐概念掌握度、学习速度、当前学习状态）。数据结构纪律：**每个画像字段必须标注证据事件类型（由哪类采集事件喂养），无证据来源的字段不允许存在**。
2. **状态层字段形状**：逐概念掌握度 = `{掌握度 0–1, 置信度, 证据计数, 最近更新}`；学习速度 = `{单位活跃时长掌握概念数, 每概念平均所需练习轮次}`，用绝对度量，不用班级百分位。数值更新机制（EWMA 或其他）归 T3。
3. **行为层 MVP**：提问构成（概念性 vs 任务特异提问比例——文献证实的最强预测轴）、投入度聚合（每周活跃天数、视频完成率、首看/重看比，均从事件信封派生）、测验过程（CFA、首次修改方向）。31 类完整对话行为分布放远期。
4. **情感/动机**：MVP 只收"求知欲"弱信号（从主动提问频次、概念性提问占比、主动重看派生）；显式情感检测（困惑/挫败，需专门检测器）放远期。
5. **背景先验定位**：年级/专业/兴趣标签仅用于冷启动先验与 L1 语境化类比，**不作为难度判断的主依据**。
6. **学生可见性**：可见 = 概念掌握地图（知识图谱上的简化掌握热力）+ 进度与投入摘要；不可见 = 置信度内部值、提问行为标签与构成分析（防止学生刷指标，古德哈特效应）。
