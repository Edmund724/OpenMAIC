# T5：分层教学策略——L2 补基础与加速加深

Type: grilling
Status: resolved
Blocked by: 05, 06, 07

## Question

定画像反哺课堂的核心机制（用户主目标）：

- 基础薄弱者如何补：沿先修链回溯插入补习模块？巩固性练习？助教讲解策略变化（L1 地基在此顺带定）？
- 学得快者如何加速加深：跳过已掌握内容、追加深化模块、提高测验难度？

对每类策略定：触发条件（画像哪个字段到什么阈值）、课堂上的具体表现（学生看到什么）、退出/回升机制（补强后如何回到主线）、防标签固化的护栏（画像误判如何纠正）。

会话开场调 Skill: grilling + domain-modeling。

## Answer

2026-09-20 经一轮 grilling 全部按推荐拍板：

1. **策略总框架：确定性规则引擎**。阈值 + 置信度 + 冷却的规则查表决定"是否动作、动作类型"；LLM 只负责动作内容（怎么讲、出什么题）。触发必须可复现、可审计、可调参。
2. **补基础（触发与表现）**：双通道触发——① 先修检查：学新内容前沿先修链查依赖概念，掌握概率 <0.6 且置信足够即触发（事前预防）；② 失败信号：当前概念测验 CFA 错误或对话标注"误解"即触发（事后补救）。表现 = 插入补习模块 + 助教进入补基础态；主线内容始终可见，**补习是插入不是替换**。阈值 0.6 为初始值，需上线校准。
3. **回升与升级（闭环内环）**：补后巩固练习通过 → 回主线，补习记录入画像证据；两轮补习未过 → 沿先修链再降一层 + 该概念进入教师可见聚合层（群体卡点是课程设计问题，与个体问题分开）。
4. **快学生分流**：加速 = 掌握 ≥0.85 且置信足够 → 标准讲解替换为摘要卡 + 3 题快速确认测，通过即跳过（确认测防 BKT 高估）；加深 = 掌握高**且求知欲信号高** → 追加深化模块 + 助教加深态；**掌握高但求知欲低 → 只加速不加深**。
5. **L1 助教策略查表**：补基础态 = 更慢、更多基础例子、提示式引导而非直接给答案（Borchers 证据）；加速态 = 精简少重复；加深态 = 苏格拉底反问、开放讨论；全程兴趣类比（身份层）。策略选择确定性，讲解表达归 LLM。
6. **防标签固化护栏（并入本票，不独立）**：① 置信度 + 时间衰减；② 学生显式声明为强证据；③ 补习插入不替换、主线始终可见可自选；④ 被标弱概念在后续测验中抽样再现（"再挑战"通道）。**L3 远期**：报告远期节写一段——加速/补基础频繁发生时大纲可按个人重排（整章跳过、深化支线展开），机制复用 L2，不展开设计。
