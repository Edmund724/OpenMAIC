§record_observation 工具

description: "Record a notable learning event mid-task (error, struggle, question)
  for the evaluator. Analytics only — this does NOT advance the task or gate
  completion. Use sparingly, for moments worth showing the evaluator."
  — lib/pbl/v2/agents/instructor.ts:1423-1470

kind: enum ['error','struggle','question']   // concept_unlocked 已不在枚举中
signature: 机器标签，LLM 自由命名（如 'undefined_variable'），不给学生看
label: 可选，人类可读名（≤60 字符，用学生内容语言）
note: 可选，一句话引用支撑该观察的学生行为（≤500 字符）

prompt 侧唯一规则（prompts/instructor-base-rules.md:232-234）："Use it sparingly, not on routine turns." 无代码级频率限制。

重复判定（记录时）：同 microtask 下已有同 signature 的 error → repeatedError=true instructor.ts:1434-1446。聚合层：repeatErrorCount = errorCount − 去重signature数 kernel/engagement.ts:143。
