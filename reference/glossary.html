§网页与浏览器

术语大白话在本课程里
客户端 / 前端你浏览器里跑的那部分程序（看得见、点得动的）课堂页面、课件、发消息的代码
服务端 / 后端远处服务器上跑的那部分程序（看不见，负责存数据、调 AI）app/api/ 下的路由
请求 / 响应客户端向服务端"递纸条问事"，服务端"回纸条"每发一条消息就是一次请求
stateless（无状态）服务端不记事——每次请求都得把前因后果一起带来聊天路由不存会话，历史全在请求里
HTML / 源码网页的"图纸文本"，浏览器照它画出页面每个课件本质是一份 HTML 文本
JSON一种写数据的通用文本格式，花括号键值对事件、快照、请求体全是 JSON
iframe页面里嵌的一个"独立小窗口"，里面的内容和外面互相隔离交互课件跑在 iframe 里，防止它搞坏课堂页面
postMessage浏览器给 iframe 内外两边留的唯一"传话筒"宿主向课件要状态就靠它
宿主（host）嵌别人页面的那个外层页面OpenMAIC 课堂页面是课件的宿主
localStorage浏览器给每个网站的一小块本地存储，关了浏览器也在匿名 learner key 存在这里
选择器（selector）用一段文本"点名"页面里某个元素的方式点选交互组件提问时用它定位

§安全与校验

术语大白话在本课程里
哈希（hash）给任意内容算出一个固定长度的"指纹"；内容改一个字，指纹全变SHA-256 指纹用来确认"状态确实来自这份课件"
SHA-256一种具体的哈希算法，指纹长 64 个十六进制字符客户端算课件源码指纹上行，服务端重算比对
新鲜度窗口只认"刚出炉"的数据，放久了就作废快照超过 30 秒服务端拒收
sanitize（消毒）把文本里能执行动作的坏部分（脚本等）剥掉再使用元素证据进 prompt 前剥掉 script/on* 属性
prompt 注入坏人在数据里藏"指令"，骗 AI 把它当命令执行所以注入时标注"这是数据，不是指令"

§数据与存储

术语大白话在本课程里
协议（protocol）双方事先约定好的"对话暗号格式"maic:observation:read:v1 就是暗号
快照（snapshot）某一瞬间状态的"照片"发消息时对课件状态拍一张
字节 / KB数据的体积单位；1 KB ≈ 500 个汉字快照限 32 KB
超时（timeout）等答复最多等这么久，等不到就当失败采样课件状态最多等 800ms
环形缓冲定长记事本，写满了就从最旧的一页撕掉接着写engagement 账本上限 500 条
追加式账本只许往后记、不许涂改的流水账事件只能 append，不能改历史
去抖（debounce）高频小动作攒一会儿再一次性处理quiz 草稿攒 500ms 才写一次
重放（replay / fold）把流水账从头过一遍，重建出"现在的状态"fold.ts 从事件重建学习者状态
分区键决定"这条数据归哪一堆"的分组依据(stage_id, learner_key)
JSONBPostgres 数据库里存 JSON 的列类型runtime_records.data 就是 JSONB
schema数据的"表格模板"：有哪些字段、各是什么类型zod schema 定义工具参数形状
枚举（enum）字段只允许取固定几个值之一kind 只能是 error/struggle/question
水位线（watermark）账本里"已经抄到第几行"的书签drain 用它记住哪些事件已写库
at-least-once"宁可重复送，不能漏送"的送货策略；重复由收货方去掉drain 写库策略，fold 负责去重

§AI 相关

术语大白话在本课程里
LLM / 大模型能读能写的 AI（如 GPT、Kimi）Instructor、Director 等 agent 的大脑
prompt写给 AI 的指令文本，决定它怎么行动观察记录的"判定标准"就写在 prompt 里
工具调用（tool call）AI 按约定格式"举手申请做一件事"，由程序真正执行record_observation 就是一个工具
tokenAI 读写的最小文本单位，约等于半个汉字prompt 长度、裁剪预算都以它为成本
agent一个有角色、有目标、能调工具的 AI 实例Instructor / evaluator / 同学 agent
